# Sdf1_login Plugin User Guide

## 1. Features

| Name | Description/Function | Status |
| :--- | :--- | :--- |
| Login | User login/registration | Completed |
| World Trash Can | Clear server drops | In Progress |
| Ticket System | User ticket submission | Completed |
| Check-in System | Check-in points for rewards | Completed |

## 2. Installation

| Prerequisite | Optional |
| :--- | :--- |
| CY_beibao | Optional |
| EssentialsX | Optional |

### 2.1 Download
Download the plugin from GitHub or Gitee, put it into the server plugin directory, restart the server.

### 2.2 Configuration Files

#### 2.2.1 messages.txt
Controls all plugin prompt messages. Execute /sdf1_login reload after modifying.

#### 2.2.2 afk_whitelist.txt
Players in this config will not be affected by AFK kick.

#### 2.2.3 SMTP Settings.txt
Controls SMTP mail server config, used for password recovery emails.

#### 2.2.4 Plugin Settings.txt
Controls the entire plugin including account limits, admin password, etc.

#### 2.2.5 chat.txt
Controls chat filter for handling illegal links.

## 3. Commands

- Sdf1_login main command
- Sdf1_login reload reload config
- reg register account
- login login to account
- l login to account
