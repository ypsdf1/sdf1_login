## 0. 项目定位

Sdf1_login 是一个「大而全」的生存服综合插件：以**登录注册**为核心，向外扩展出经济（债券/积分）、商城与二手交易、领地保护、用户组、传送与家、任务、签到、PVP、工单、公告板、封禁公示、物品 SN 防刷、箱子搬运、Web 面板等一整套生存服基础设施。

项目由两端组成，配套使用：

| 端 | 位置 | 职责 |
| :--- | :--- | :--- |
| **Java 插件** | 本仓库根目录 | 游戏内全部逻辑与权威数据 |
| **PHP Web 端** | 同仓库 `../Web`（或独立部署） | 玩家网页面板、管理后台、收银台、在线充值、正版 OAuth 回调 |

两端通过 `sync.php` 接口 + SQLite 共享队列通信：Java 每 5 秒轮询 Web 端队列，Web 端的购买/充值/领地变更最终由 Java 执行。**Java 是游戏数据的权威源，Web 只做展示与排队。**

## 1. 功能介绍

### 1.1 账号与安全

| 功能 | 说明 |
| :--- | :--- |
| 登录 / 注册 | `/reg`、`/login`、`/l`，主密码 + 临时密码双轨验证 |
| 邮箱体系 | 绑定邮箱、邮箱验证码、忘记密码、临时密码邮件 |
| 正版登录 | `/mslogin` 走 Microsoft OAuth，完成正版绑定与自动登录 |
| 二次验证（2FA） | `/2fa` 绑定 TOTP（1Password / Microsoft Authenticator 等），支持恢复代码与控制台强制解绑 |
| IP 限制 | 同 IP 最大账号数、同 IP 转账限制 |
| 登录风控 | 密码连错临时封禁 + 邮件告警；异地登录提醒 |
| 账号审批 | 注册审批支持 AUTO / MANUAL / HYBRID 三种模式 |
| 维护模式 | 独立白名单 `白名单.txt`，支持定时窗口、24 小时硬封顶、OP 绕过 |
| OP 白名单 | 接管原生 OP 名单，白名单外持 OP 会被自动撤销并报警（仅控制台管理） |

| 功能 | 说明 |
| :--- | :--- |

## 2. 安装说明

### 2.1 环境要求

| 项目 | 要求 |
| :--- | :--- |
| 服务端 | Paper 26.x（API 1.21+）；Spigot 未测试 |
| Java | JDK 25 及以上 |
| 数据库 | SQLite（插件内置 `sqlite-jdbc`，无需额外安装） |
| 可选 | PHP 8.x Web 端（需要网页面板/在线充值时） |

### 2.2 前置与可选插件

| 插件 | 类型 | 作用 |
| :--- | :--- | :--- |
| [CY_beibao](https://git.ypshidifu.cn/youpaishidifu/CY_beibao) | 可选，推荐 | 云背包，积分商城可购买背包容量 |
| [sdf1](https://git.ypshidifu.cn/youpaishidifu/Sdf1_plugin) | 可选，推荐 | 远程 CDK 兑换系统 |
| EssentialsX | **不再支持** | 本插件已移除 Vault 经济依赖，统一使用内置债券系统 |

### 2.3 安装步骤

1. 将 `Sdf1_login.jar` 放入服务端 `plugins/` 目录。
2. 启动服务端，插件会自动生成配置目录 `plugins/Sdf1_login/`。
3. 关闭服务端，按需修改配置文件（至少修改 `插件设置.txt` 中的管理密码）。
4. 重新启动，控制台出现 `[Sdf1_login]启动完毕` 即加载成功。
5. 如需网页端：部署 `Web/` 到 PHP 站点，并让 Java 端与 PHP 端的通信密钥保持一致（见第 6.13 节）。

### 2.4 首次启动必做

| 序号 | 事项 | 位置 |
| :---: | :--- | :--- |
| 1 | 修改管理员面板密码 | `插件设置.txt` → `管理密码` |
| 2 | 确认管理标签 | `插件设置.txt` → `管理标签`（默认 `admin`） |
| 3 | 配置 SMTP（找回密码/告警邮件需要） | `SMTP设置.txt` |
| 4 | 按需开启挂机踢出、垃圾站、维护模式 | `插件设置.txt` / `白名单.txt` |
| 5 | 配置菜单与商品 | `菜单.txt` / `shop/*.md` |
| 6 | Web 端首次部署后立即设置强密码并启用二次验证 | Web 端 `admin_2fa_setup.php` |

> ⚠️ 管理密码、SMTP 密码、Web 通信密钥都属于敏感信息。请勿把填写真实值的配置文件提交到任何公开仓库。

### 2.5 从源码构建

```bash
mvn clean package
```

产物：`target/Sdf1_login.jar`。

### 4.3 SMTP设置.txt

用于邮箱验证码、找回密码、异地登录/2FA 告警。支持 GUI 配置，也可手工修改；重载生效。

```txt
# ===== SMTP 邮件服务器配置 =====
smtp地址=smtp.example.com
smtp端口=465
smtp账号=mail@example.com
smtp密码=请填写你自己的SMTP授权码

smtp加密=true
验证码接收邮箱=example@example.com
```

### 4.4 挂机白名单.txt

每行一个玩家名。开启挂机踢出后，名单内玩家不会被踢。

### 4.5 白名单.txt（维护模式）

独立于原版白名单，分「控制段」和「白名单段」。

```txt
# ===== 控制段 =====
启用 = false
开始时间 = 2026-01-01 20:00
结束时间 =
时长 = 24h
OP可绕过 = true
消息 = &c&l[服务器维护] &7服务器正在维护中，请稍后再试（结束时间: &e{结束时间}&7）

# ===== 白名单段 =====
[白名单]
Steve
Alex
```

- 时间支持：10 位秒级时间戳、13 位毫秒时间戳、`yyyy-MM-dd HH:mm`、`2026年9月28日14时30分`、只写 `HH:mm`（今天）。
- 未填结束时间/时长时默认 24 小时；单次维护最长 24 小时，到点自动结束。
- 拦截发生在异步预登录阶段，未授权玩家不会收到任何世界数据包。

## 6. 核心系统说明

### 6.1 登录与账号安全

**双轨验证**：玩家注册时生成随机的 `password_salt`，密码以 `SHA-256(salt + password)` 存储。登录既接受主密码，也接受管理员下发的临时密码（5 分钟有效、一次性）。

**登录流程**：

1. 玩家进服后处于冻结状态（不能移动/交互/受伤），收到登录提示。
2. 未注册 → `/reg`；已注册 → `/login`。
3. 超时未登录（默认 60 秒）踢出。
4. 同一 IP 在 5 分钟内重连可免密自动登录（可配置）。

**风控**：

- 密码连续错误达到阈值（默认 5 次）→ 临时封禁（默认 300 秒）+ 邮件告警。
- 异地登录 → 向绑定邮箱发送提醒。
- 同 IP 注册账号数超限 → 拒绝注册。
- 被拉黑玩家 → 无法登录 Web、无法创建领地、无法消费。

**2FA**：

- 需要先绑定邮箱。
- `/2fa add` 生成 10 分钟有效的绑定申请与二维码链接。
- 绑定成功后生成 8 组恢复代码发到邮箱；恢复代码可一次性解绑。
- 登录时若 IP 变更或主动验证，会要求输入 6 位动态码。

**正版登录**：

- `/mslogin` 生成 Microsoft OAuth 链接，玩家在浏览器完成授权。
- 回调经 MS token → Xbox → XSTS → Minecraft token → profile，校验通过后自动登录。
- 正版 UUID 与离线 UUID 不一致时，由 `VerificationManager` 做兼容处理。

### 6.2 债券与积分

- **债券**是主货币，存放于 `bond.db`，所有加扣都必须经过 `BondManager`，每笔写流水。
- **积分**存放在 `login.db` 的 `users` 表，主要来源：签到、任务、邀请、工单服务商奖励。
- 积分唯一消费出口是积分商城（兑换债券、云背包容量、经验等），兑换比例由 `PointsManager` 控制。
- 管理员可用 `/cypay give|remove|freeze` 调整债券；所有操作有流水，可用 `/printer` 导出。

### 6.3 商城与二手商店

**普通商店**：

- 商品来自 `shop/*.md`，按文件分分类。
- 支持库存、每小时销量、总销量、限购、打包（潜影盒）、优惠券。
- 结算时校验余额与库存，写订单与小票；发货失败自动退款并贴标。
- 管理员可修改价格/库存，改动会同步到 Web 商城。

**二手商店**：

- 玩家用 `/shopbuy` 上架物品，平台担保。
- 上架数量、最低售价、手续费比例、手续费支付方均可配置。
- 卖家可选择「卖方出手续费」或「买方出手续费」。
- SN 物品与宝箱物品禁止上架。

### 6.4 领地与用户组

- 领地核心为 `AreaProtection`，数据在 `area_effects.db`；命令行入口 `AreaCLIManager`，GUI 入口 `AreaGUIManager`。
- 支持：创建/扩建/收缩/删除、转让、成员与访客、权限细分（PVP、爆炸、火焰、饥饿、摔伤、展示框交互、容器、拾取等）、违禁品没收、领地商店、传送点。
- 用户组（`UserGroupManager`，`usergroup.db`）决定：领地上限、每平米价格、home 上限、效果数量/等级上限、组前缀与颜色、付费加入/续费价格。
- 领地是**权威数据源**：Web 端的领地改动只写队列，由 Java 执行后回推最终状态。
- 原「区域防护」已合并进领地系统，`/protect` 直接复用原区保指令；完整的 `/protect` 参数、区域配置文件写法与生物属性对照表见第 7 节。

### 6.5 垃圾站

- 定时清理地图上的掉落物，默认每 300 秒一轮。
- 顶部血条显示倒计时，临近清理变黄/变红。
- 最后阶段按 Q 丢弃可触发「抢救」，或管理员执行 `/垃圾抢救` 取消本轮。
- `垃圾站_保留轮数=N` 表示每 N 轮真正倒一次垃圾，其余轮次只提示。
- `垃圾站_启发式拦截` 关闭后不再做红区 title 警告与双击 Q 拦截，但血条仍显示。

### 6.6 封禁公示与黑名单

**封禁公示（耻辱台）**：

- 数据源是原版 `banned-players.json`，不是 Bukkit 内存名单（避免重启/Web 改写后不一致）。
- 按配置的间隔轮播被封禁玩家、理由与时间。
- 支持「由近到远 / 由远到近」、播报起点、关闭播报。
- 玩家进服时也会收到一条插播。

**软折磨黑名单**：

- 通过 `/addblack` 或直接编辑 `black/黑名单.md` 添加。
- 被拉黑玩家：不能消费债券、不能登录 Web、不能创建领地、不能成为授权玩家、不能破坏/放置/开容器/拾取/村民交易，背包清空前备份。
- 聊天正常，但每条消息会被追加「我是罪人」签名。
- 到期自动解除并恢复背包与权限；删除条目 5 秒内恢复。

### 6.7 SN 物品防刷

- 每件受管物品带唯一 SN，记录：物品类型、归属、状态、位置（玩家/容器/世界坐标）、所在领地、最后出现时间、报失次数等。
- Java 端为权威源，定时把目录、日志、库存、手持快照推送到 Web 端。
- 支持：报失、注销、补办、永久绑定、管理员强制操作。
- Web 端的操作写入 `web_sn_commands` 队列，由 Java 执行并回写结果。
- 注销后进入冷静期（默认 1 小时），期间禁止申领。

### 6.8 箱子搬运

- 触发条件：领地主/授权成员/管理员，手持带**精准采集**的斧头，拆除领地内的箱子。
- 首拆后挂起 2 秒观察：2 秒内再拆一个箱子 → 成组，两个箱子各交付一个打包箱；超时 → 只处理被拆的那一个。
- 打包箱放置后自动回填物品；双箱会按 54 格处理。
- 非授权玩家拆箱仍交还原版（物品散落，且领地可禁止拾取）。
- 开关与「是否合并两个箱子」在 `chest/cfg.json`。

### 6.9 JSON 消息构造器

- `/json` 打开 27 格面板，支持三种模式：tellraw 原生 JSON、大标题、小标题。
- 颜色行支持自定义颜色与调色板（`json解码配置/解码配置.md`）。
- 文字在聊天栏输入，发送时以玩家身份执行原版指令，天然受原版权限约束。
- 原版 `title` / `tellraw` 报错时，插件会接管报错并直接打开构造器。

### 6.10 公告板

- 侧边栏计分板轮播 `公告/公告.md` 的内容。
- 支持开关、翻页时间、颜色继承、15 字截断换行、可点击链接。
- 与 PVP 侧边栏共存；切换世界后自动重刷。

### 6.11 工单与服务商

- 玩家在面板提交工单，支持 Markdown 与图片附件。
- 状态：已提交 → 已回复 → 已完结 / 已撤销。
- 管理员可分配、驳回、完结；服务商可抢单。
- 服务商由管理员在游戏内工单管理面板授权，奖励按 `服务商积分倍率` 结算。

### 6.12 聊天增强

- 违规域名：按 `illegal_domains.txt` 后缀匹配，`http` 开头与未加白 IP 一律拦截；命中后按 `chat.txt` 梯度处罚。
- 敏感词、广告机检测、禁言（持久化到 `users.muted_until`）。
- 英文消息自动机器翻译，并以双语形式展示（原文由 MC 正常处理，翻译在原文后追加）。
- 控制台发言可用 `/conmsg` 设置署名，未匹配到指令的控制台文本会作为聊天广播。

### 6.13 Web 端联动

- Java 端 `WebManager` 负责：Token、商城同步、CDK 验证、余额、注册同步、领地/用户组/封禁同步、登录请求轮询。
- **通信密钥必须与 Web 端 `config.php` 的 `SECRET_KEY` 完全一致**，否则所有同步接口返回 401。
- 相关配置写在 `插件设置.txt`：`web通信-启用`、`web通信-地址`、`web通信-密钥`、`web通信-同步间隔分钟`、`web通信-Token有效期秒`、`web通信-回调端口`。修改后会自动热重载，无需重启。
- 同步方向：
  - Java → PHP：商品、债券、流水、登录、在线玩家、领地、权限、用户组、封禁、SN 等。
  - PHP → Java：通过 `web_transactions`、`sync_requests`、`web_admin_changes` 等队列，Java 每 5 秒轮询消费。
- Web 端部署与配置详见 `Web/readme.md`；通信细节详见 `Web/代码关联关系.md`。
- 首次部署 Web 端后，请立即访问 `admin_2fa_setup.php` 设置强密码、IP 白名单与二次验证。

### 6.14 运维与自愈

- **自动备份**：每小时第 0/15/30/45 分准点备份在线且已登录玩家的背包，跳过拉黑玩家；备份可用于登录自愈与手动恢复。
- **模板自愈**：启动时扫描 jar 内所有模板；数据目录缺文件则释放，缺配置项则先备份 `.bak` 再补齐，用户改过的值原样保留。
- **主线程看门狗**：主线程静默超过阈值时自动打印线程栈，便于定位卡顿。
- **更新检查**：启动时异步检查 Gitea / GitHub / Gitee，可在配置中关闭。
- **维护模式**：见 4.5；到点自动结束，无需重启。
- **OP 白名单**：见 4.16；原生 `/op` 会被引导到 `/opwl add`。

## 7. 领地保护指令（原区域防护）

> 区域防护已合并进领地系统，`/protect` 直接复用原区保指令。本节保留该指令的完整参数、区域配置文件写法与生物属性对照表，作为领地保护的详细参考。

区域保护用于保护主城、展示区、活动场地等不希望被破坏/交互/袭扰的区域。

| 指令 | 参数 1 | 参数 2 | 参数 3 | 结果 |
| :---: | :---: | :---: | :---: | :--- |
| protect | 无 | 无 | 无 | 帮助信息 |
| protect | add | 区域名 | 玩家名 | 加白指定玩家到区域 |
| protect | add | 玩家名 | 无 | 加白指定玩家为全局 |
| protect | additem | 区域名 | 物品名 | 加黑指定物品到区域 |
| protect | additem | 物品名 | 无 | 加黑指定物品到全局 |
| protect | addname | 区域名 | 名字 | 加白指定生物名字到区域和平模式白名单 |
| protect | addplayer | 区域名 | 玩家名 | 加白指定玩家到区域强制模式豁免名单 |
| protect | remove | 玩家名 | 无 | 移除玩家全局白名单 |
| protect | remove | 区域名 | 玩家名 | 移除玩家区域白名单 |
| protect | removeitem | 物品名 | 无 | 删除全局黑名单物品 |
| protect | removeitem | 区域名 | 物品名 | 删除区域黑名单物品 |
| protect | removename | 区域名 | 名字 | 删除区域和平模式白名单 |
| protect | removeplayer | 区域名 | 名字 | 删除区域强制模式豁免名单 |

示例：

- `/protect add 末地保护区 players` 添加 players 到末地保护区
- `/protect removeitem 主城区 TNT` 从主城删除 TNT 黑名单
- `/protect 筑城区 addwhite zhangsan` 把 zhangsan 加白到筑城区

所有参数**任意排序**，区域名与玩家名可前后互换，插件会自动识别。

| 参数 | 效果 |
| :---: | :--- |
| 和平模式 | 所有敌对生物全部进虚空 |
| 禁止袭击 | 清除玩家身上的袭击效果，灾厄村民进虚空 |
| 清除XX效果 | 立即清除玩家身上的效果 |
| 给与XX效果 | 按配置给予指定等级、时长的效果 |

区域配置文件支持 `//`、`#`、`/* */`、`<!--- --->` 注释：

```txt
# 区域: 主城区
起点: world,-130,-713
终点: world,-427,-560
高度范围: 0-255

没收物品: 蘑菇,毒蘑菇
禁止PVP
禁止摔伤
禁止饥饿
禁止一切伤害
// 和平模式
禁止袭击
禁止交互展示框
// 清除所有效果
效果 村庄英雄 255 999999
禁止爆炸
禁止使用物品: TNT
进入提示: 欢迎来到保护区
离开提示: 已离开保护区
没收提示: 你的违禁品已被没收
通报批评: §c§l{player} §f在{area}违规携带违禁品，被没收 §e{count}§f件！
```

## 11. 常见问题

**Q：启动后提示「数据库被锁定 / database is locked」？**
A：确认没有多个服务端实例同时使用同一数据目录；不要把 `plugins/Sdf1_login` 放在网络盘/NFS 上；备份时先停服。

**Q：玩家登录后仍然不能动？**
A：检查是否被拉黑、是否处于维护模式、是否未完成 2FA 验证；查看控制台是否有风控/黑名单日志。

**Q：修改了配置但不生效？**
A：多数配置支持 `/sdf1_login reload` 或增量热重载；`插件设置.txt` 的部分键、垃圾站、黑名单、公告、二手规则会在运行中自动检测。数据库结构变更需要重启。

**Q：Web 端所有接口返回 401？**
A：Java 端与 Web 端的通信密钥不一致。检查 `插件设置.txt` 中的 `web通信-密钥` 与 `Web/config.php` 的 `SECRET_KEY` 是否一字不差；同时确认 `web通信-启用=true`、`web通信-地址` 指向正确的站点目录。

**Q：玩家收不到找回密码邮件？**
A：检查 `SMTP设置.txt` 的服务器、端口、账号、授权码与加密方式；部分邮箱需要使用「授权码」而不是登录密码。

**Q：资源包一直强制下载 / 玩家拒绝后被踢？**
A：确认 `radio/ogg/` 下是否有 ogg 文件；不需要广播时清空该目录。检查 `radio_config.txt` 的 `resource-pack-url` 是否可访问。

**Q：如何彻底卸载？**
A：停服后删除 `plugins/Sdf1_login/` 与 `plugins/Sdf1_login.jar`。如需保留数据，先备份整个目录（含 WAL/SHM 文件）。
