## 软折磨黑名单配置

功能说明：<br>
此功能为软折磨，用于折磨违反规则的玩家。通过`/addblack user time(可选) msg(可选)`添加违规玩家或直接编辑本文件即可。被拉黑的玩家不能消费债券、不能登录PHP后端、不能创建领地，不能成为他人领地的授权玩家。不能破坏、放置方块，不能打开任何容器、不能拾取任何物品、不能与村民交易，没有背包(清空前备份，自动备份跳过该玩家)。能说话但，会被系统加上"---我是罪人user"的签名

## 示例配置:
| 玩家名字 | 拉黑时长 | 理由 |
| --- | --- | --- |
| steve | 终身 | 违反服务器规则 |
| Dream | 2026-10-20 14:30 | 随意殴打他人 |

## 指令集

| 前缀 | 参数1 | 参数2 | 参数3 | 
| --- | --- | ---| --- |
| /addblack | user | time | msg |
| /removeblack | user | 空 | 空 |
| /addblack | steve | 2026-10-20 10:00 | 违反服务器规则 |
| /addblack | Dream | 0 | 空 |
| /removeblack | Notch | 空 | 空 |

- 备注：0表示永久拉黑，填入日期+时间则表示遵循到期时间。填入日期则表示以当天23:59:59为界限。填相对时长（30分 / 2小时 / 3天 / 1周）= 从拉黑那一刻起算，到期自动解除并自动恢复背包与权限<br>
- 生效规则: 定时，每分钟的第0秒、5秒、10秒...以此类推、55秒定时增量重载，删了5秒后立即恢复背包和各项权限，加了5秒后立即生效
