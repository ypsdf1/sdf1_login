## ----配置区开始----

| 名字 | 功能说明 | 参数值 |
| --- | --- | --- |
| 轮播最低间隔 | 最短是多少秒一次(建议阈值60，太低很吵) | 60 |
| 轮播最大间隔 | 最长多少秒一次(建议阈值300以内，太长起不到效果) | 180 |
| 播报模式 | 是由远到近(即从第一个封禁的玩家开始报到最后一个)，还是又近到远(从最新一个被封禁的玩家播报到第一个被封禁的玩家)。此项填0或最大最小间隔都为0表示关闭播报 | 由近到远 |

```json
{
  "最小间隔":"",
  "最大间隔":"",
  "播报模式":true,
  "解释说明":{
    "播报模式":"true表示开启播报又近到远，false表示开启播报由远到近。0为关闭",
    "最小间隔":"最短是多少秒一次(建议阈值60，太低很吵)",
    "最大间隔":"最长多少秒一次(建议阈值300以内，太长起不到效果)"
  }
}
```

## ----配置区域结束----

## 功能说明
- 此功能为服务器打造一个不可拆解的耻辱台，展示所有被封禁的玩家。json代码块的参数值和md表格是2选1，你可以删了表格，留json则表示用json作为配置值，也可以删了json用表格。小白用户推荐使用md，因为最简单，专业人员推荐使用json，因为最清晰，没有注释(注释是另起一行，不在配置块)。<br>
- 同时兼容.json直接作为配置文件
